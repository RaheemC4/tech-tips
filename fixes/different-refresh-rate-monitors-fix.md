# Different Refresh Rate Monitors Fix

*Category: Fixes | Originally posted: 2023-05-07 | 1 message(s)*

If you have multiple monitors (2+) and they are different refresh rates, use this fix to help mitigate windows stuttering and refresh rate mismatches that can occur. This is for NVIDIA GPUS ONLY




Download NvidiaProfileInspector.zip from the link provided

Open nvidiaProfileInspector.exe

Go down to "5 - Common"

Find Multi-display/Mixed-GPU acceleration

Make sure it is set to Multi Display Performance Mode

Click Apply
Restart PC

Make sure to check this setting is still set every time you update your GPU drivers
