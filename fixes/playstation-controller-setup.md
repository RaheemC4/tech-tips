# Playstation Controller Setup

*Category: Fixes | Originally posted: 2024-03-01 | 1 message(s)*

Playstation Controllers are not native to PC and so in some games they will cause errors like double inputs -> 2nd player spawning in or it wont register any inputs at all

To Fix this we will be using a combination of DS4Windows + HidHide to have your Playstation controllers always register as XBOX Controller Input. That way you wont face any issues in any game that supports controller.


https://ds4-windows.com/download/ryochan7-ds4windows/


Download and Open DS4Windows
Install ViGEmBus Driver
Install HidHide Driver

Open HidHide Congiruation Client
Press + in the bottom right
Select DS4Windows.exe
Press Open
Go to Devices tab and tick your Playstation controller ONLY (DONT TICK ANYTHING ELSE IN THE DEVICES BOX)
Tick Enable Device Hiding
DONE

YOU NEED TO OPEN DS4WINDOWS EVERY TIME YOU WANT TO PLAY A GAME WITH CONTROLLER
