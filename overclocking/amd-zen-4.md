Theres only one answer... 7800X3D. If you're building a high end PC this is the only AMD cpu option. Other AMD cpus cannot compete with comparable intel cpus as well as having less cores meaning multitasking will be a struggle.

**What RAM Should You Buy?**

My recommendation is going to be any Hynix M-Die based memory. Yes this is not as new as A-Die or can clock as fast but what it can do is have much tighter timings, allowing for lower latency, which we want on Zen4. Memory capacity is all up to what you need. I will say that 32gb will be enough for most people.

**What Motherboard Should I Buy**

This is all up to what you need in a motherboard. I'll list a few things that I find important in a motherboard in 2023
BIOS Flashback
Onboard Debug (POST Code or Debug Leds)
Clear CMOS Button
Intel LAN
Wifi/BT
3+ m.2

What chipset you need is up to you. B650E is the best option as it doesn't break the bank and still gives you PCIE Gen5 meaning it will support new SSDs as the come out. Listed below is a chart of what every chipset gives you:
