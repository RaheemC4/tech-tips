Discord Voice and Video Settings

If you have a dedicated mic on pc that isnt on a headset, give turn off all the discord noise processing to get better quality out of the mic. if ur mic echos then turn either noise reduction on or echo cancellation on one at a time to to see which reduces the echos the most. in most scenarios dont use the krisp noise suppression as it makes the mic sound really bad but for some mics you will need it on or youll have really bad echoing.



NOISE GATE


In discord voice and video settings there is an option to enable manual Noise Gate. this is a setting that stops ur mic from activating/picking up sound and outputting it if there is not enough volume being put into the mic capsule. basically, if u have light breathing/buzzing in the background/wind it wont pick it up/pick up very little if you set it up correctly. to enable this option, go to discord voice and video settings and untick Automatically determine input sensitivity.

To set this up properly, you want to speak normally and have ur voice go above the threshold (past the yellow into the green). but when ur not talking and there is general noise, u want that low volume noise to be below the threshold (within the yellow before the green).
